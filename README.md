# スクリーンショット・レイアウト

ブラウザだけで動く、スクリーンショットや画像をA4/A3などの用紙上に自由に配置してPNG書き出し・印刷できるツールです。サーバー不要・インストール不要、`index.html` を開くだけで使えます。

**🔗 デモを開く：** `https://celestial-globe.github.io/layout_tool/`
（GitHub Pages を有効化すると自動でこのURLが使えます）

## 主な機能

- 📋 クリップボードから直接貼り付け（Ctrl+V / ⌘+V）、ドラッグ&ドロップ、複数選択にも対応
- 📐 用紙サイズ（A3〜B5、Letter、Legal）と縦横の切り替え
- 🖱️ 画像の移動・リサイズ・複製・重なり順の変更、スナップ機能付き
- ↗️ 矢印・丸・テキストによる注釈機能
- 🏷️ ファイル名と日時のキャプション自動表示（編集可能）
- ↶ Undo / Redo、矢印キーでの微調整移動
- 💾 レイアウトをJSONで保存・読み込み（画像データも含む）
- 🖼️ PNG書き出し、印刷（用紙サイズに正しく合わせて出力）

## 使い方

1. このリポジトリの `index.html` をブラウザで開くだけ（ローカルでもOK、サーバー不要）
2. 「＋ 画像を追加」またはドラッグ&ドロップ、貼り付けで画像を配置
3. 自由に並べ替えて「PNG書き出し」または「印刷」

## ローカルで動かす

```bash
git clone https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
# index.html をダブルクリックして開くだけ
```

## GitHub Pages で公開する

1. GitHubのリポジトリ画面で **Settings → Pages** を開く
2. Source を `Deploy from a branch` にし、Branch を `main` / `/(root)` に設定して保存
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能になります

## 技術

- 依存ライブラリなし。素のHTML / CSS / JavaScriptのみ
- 画像はブラウザ内メモリのみで扱われ、外部サーバーには一切送信されません
